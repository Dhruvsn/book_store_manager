== Overview

The BookStore Manager is a dual-mode E-commerce application:
1. **Local Mode (`app.py`)**: Uses RAM-based storage (dictionaries) for fast development and testing without AWS dependencies.
2. **Cloud Mode (`aws_app.py`)**: Designed for AWS EC2, utilizing DynamoDB for persistence and SNS for real-time notifications.
